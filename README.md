# LE STUDIO · Social OS

App de gestión de clientes y marcas de LE STUDIO.

- Web: https://social.lestudio-crea.com (Cloudflare Pages, proyecto `lestudio-os`).
- Cada cambio en la rama `main` se publica solo. Carpeta publicada: `public/`.
- Base de datos: Supabase (proyecto «LE STUDIO OS»). Scripts en `sql/`, funciones en `supabase/functions/`.
- Guías: `LEEME.md` y `ACTUALIZAR-v2.6.md`.
